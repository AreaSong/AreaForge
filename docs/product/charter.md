# AreaForge Charter

## 产品定位

AreaForge 是一个面向个人长期备考的自我锻造与考研督战系统。

它不是普通打卡软件，也不是单纯待办清单，而是围绕一个长期目标持续追踪学习投入、任务完成、知识掌握、错题复盘、状态波动和阶段风险的私人作战台。

产品采用 `A -> B` 渐进式路线：先保持个人长期备考闭环完整、默认私有和自托管友好，再逐步增加邀请制多人 Workspace、预设角色权限、数据生命周期、受控运维和主动加入的学习挑战。多人能力不得把产品改造成通用团队项目管理工具，也不得削弱个人用户的完整使用路径。

## 目标模型

- 用户在当前考试工作区定义自己的考试方向、目标日期和科目，不使用仓库作者的个人目标作为运行时默认值。
- 可按需安排第一次同步自测和后续模拟；这些节点来自真实模拟考试记录。
- 科目与分组由用户创建，也可显式选择模板；普通 seed 不创建业务科目。
- 稳定 Release 和生产仍是单人私有应用，电脑为主，手机补充访问；v1.4 邀请制身份与 Workspace/Membership 已进入默认关闭的本地候选，未完成 Release/生产前不得写成线上能力。

## 命名

产品名：AreaForge。

- `Area` 延续 AreaFlow、AreaMatrix 产品体系。
- `Forge` 表示锻造、淬炼，把当前的自己打造成更强的自己。

中文气质关键词：

- 锻造
- 督战
- 复盘
- 压强
- 长期主义
- 冷静但不麻木

## 核心原则

1. 先让用户每天回来。
2. 数据必须推动行动。
3. 鞭策必须和状态相关。
4. 狠但不摧毁。
5. 数据和代码分离。
6. 默认私有、最小授权，分享必须可见且可撤销。
7. 平台能力服务学习闭环，不让排名、权限或运维入口反客为主。

## 核心闭环

```text
首次设置 -> 今日判断 -> 行动执行 -> 活动收口 -> 可选证据 -> 每日复盘 -> 行动安排 -> 周月校准
```

AreaForge 先帮助用户开始并完成一次真实行动，再用证据、复盘和周期判断调整下一步；任务和 AI 都服务于行动，不替代行动。跨模块流程、状态语义、当前实现和后续机会以 `docs/product/learning-loop.md` 为准。

## 当前版本边界

- 私有 Web 应用。
- 电脑端优先。
- 响应式适配手机。
- 数据部署在自己的服务器。
- AI 只做建议和表达，不直接改写用户记录。

当前稳定版本不提供公开平台、多用户排名、小程序或原生 App。v1.4 本地候选先建立邀请制 Workspace 和 OWNER/MEMBER 归属，角色授权、数据生命周期、私有挑战和排名按 v1.5-v1.8 依次承接；全站公开社区、企业组织树、计费、SSO/SCIM、小程序和原生 App 仍需独立产品决策。
