# 后台任务准入配额

## 范围与配置

配额只约束显式创建的持久 EXPORT、SEARCH_INDEX_REBUILD、RANKING_REBUILD 任务，不是学习写入限制、成员/存储配额或计费系统。
学习、搜索直查、通知、删除、下载和已有任务的暂停/恢复/取消/重放沿用原授权与生命周期规则，不经过新准入检查。
实现及验收状态见[平台加固任务](../../tasks/backlog/0045-platform-hardening.md)。

`DATA_JOB_QUOTA_ENABLED` 默认关闭。开启后必须显式提供 `DATA_JOB_QUOTA_MAX_ACTIVE_JOBS` 和
`DATA_JOB_QUOTA_MAX_EXPORTS_24H`；两者使用 `0` 或不以零开头的十进制整数字符串，最大 `2147483647`。零表示不接受新的相应请求，没有默认生产阈值。
缺失或非法配置使新准入失败，但不得使通用身份配置解析失败，从而阻断登录、学习、查询或既有任务控制。

## 分区与计数

策略作用于请求者 × scope × Workspace。账户导出独立使用请求者的 ACCOUNT 桶；工作区任务使用本人在该 Workspace 的桶。
不同用户、不同 Workspace 不互相消耗名额；该策略不是跨 Workspace、全站或操作系统进程并发总量限制。
所有生产者必须使用一致配置；部分旧构建或关闭模式混跑不构成配额保证。

- 只计三个受控 kind 的持久协议任务。
- 活跃名额计算有效期内的 QUEUED、RUNNING、PAUSED、CANCEL_REQUESTED 和 FAILED。失败仍可重放，故保留名额。
- 成功、已确认取消或过期释放名额；运行中取消须等原协议确认，不能提前腾出名额。
- EXPORT 使用滚动 24 小时已接纳数，取消、失败和完成不退次数；未来时间记录也保守计入，避免时钟回拨释放额度。
- 相同幂等键先复用原任务；恢复、自动重试和人工重放不新建任务、不重复计数，也不重新执行准入限制。
- 复用既有任务记录，不新增使用历史、删除后账本或额外留存；整个账户/Workspace 生命周期结束即结束对应桶。

## 事务与失败

授权、同键绑定、额度检查和插入都在原请求事务内；同键异范围仍拒绝。开启配额时三个入口使用 Serializable，
共同入队同时校验隔离级别并取得分区级非阻塞 advisory 锁。只有进程锁不能防止旧快照漏计；可序列化冲突必须拒绝或重试新事务。
计数与插入同事务，拒绝或提交前崩溃不会留下任务、审计或搜索代次副作用。新受控记录使用准入时数据库时钟；关闭模式保持原时间语义。

超限使用 HTTP 429 与中文恢复提示；配置不可用、隔离不支持或锁竞争返回有界服务错误，不输出内部计数、配置原文或数据库异常。
关闭配额只撤回准入约束，不修改任务、原域开关、权限或源数据。

## 验证边界

专属 QUOTA 合成库验证三域真实入队、分区、并发/幂等、时间和额度边界、旧快照、强杀回滚与既有任务控制。
浏览器复用测试池匹配源码的实例，覆盖桌面与窄屏超限反馈和恢复。
配额验收不运行业务消费者，不证明 ZIP、索引、排名发布、共享环境、生产或完整平台配额已交付。
