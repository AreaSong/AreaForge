# 活动计时

## 目标

计时用于记录三类互斥活动：`STUDY` 自由学习、`REVIEW` 专项复测/复习、`TEST` 模拟考试。三类活动分别计时、分别展示主题，但同一用户全局只能有一个活动 session。

`/focus` 只负责自由学习：开始前只选择科目，不绑定任务、考纲、知识点或默认目标时长。专项复测和模拟考试必须分别在 `/test/retests`、`/test/simulations` 配置完成后，才可以启动各自的专用计时器。

## 状态机

```text
idle -> running -> paused -> running -> closing -> completed

`closing` 是冻结收口状态：进入收口的瞬间记录 `endedAt`，时间不再增长；只有结果、真实最小产出和下一动作完整提交后才进入 `completed`。未达成时必须记录受阻原因；关联正式任务时才要求选择任务去向。理解程度、专注度和精力是可选自评，不用默认值补造事实。
```

服务端与本地优先队列共同记录：

- `startedAt`
- `pausedAt`
- `endedAt`
- `accumulatedPauseSeconds`
- `effectiveMinutes`
- `closeoutVersion`
- `clientDeviceId` / `clientDeviceLabel` / `lastHeartbeatAt`

开始命令必须携带客户端生成的 `idempotencyKey`。服务端按用户、工作区、启动参数和幂等键保存创建回放：响应丢失时重复提交会返回原 session，不会新增计时；同一键提交不同参数会阻止重放。没有活动时才创建，若其他标签页或设备已经创建活动，则返回已有活动供客户端跳转。

## 专注模式

未开始计时时，`/focus` 直接展示大型数字计时器和指针式秒表视觉。

点击开始后：

- 计时器区域放大。
- 显示当前科目、任务、大纲节点、学习时长。
- 其他信息弱化或收起。
- 提供暂停、继续、结束。

复测和模拟考试沿用同一计时状态机，但入口、来源对象、主题色和收口字段不同。顶部公共工具栏显示当前活动类型、对象和时长；切换标签页或设备不会创建第二个计时器。

| 活动 | 启动前置 | 计时主题 | 结束后必填 |
|---|---|---|---|
| 自由学习 | 仅科目 | 蓝绿色 | 结果、真实最小产出和下一步；未达成原因与任务去向按条件出现 |
| 专项复测 | 科目、知识点和复测范围 | 橙/蓝色 | 逐点量化结果、个人反馈、复测总结和复盘 |
| 模拟考试 | 考试、科目和考试时长 | 琥珀色 | 分科成绩、失分、心态、整场总结和显式复盘 |

## 结束收口

自由学习结束后默认必须记录：

- 结果：达成、部分达成或未达成。
- 最小产出。
- 下一步动作。

有效性与低转化由服务端依据真实时长、产出和结果归一化；理解程度、专注度与精力可选，缺省保持未知。

`/settings/learning` 提供当前设备的收口模板：用户可修改实际产出提示、下一动作提示和可选复盘默认展开状态。该偏好只保存在当前浏览器，不能写入收口字段、不能生成默认答案，也不跨设备同步。

## 边界

- 同一用户全局只允许一个 `RUNNING`、`PAUSED` 或 `CLOSING` session；多个标签页和设备都回到同一个活动。
- 刷新页面后应恢复 active session。
- 不每秒写数据库。
- 跨午夜按用户时区归属学习日，第一版默认 Asia/Shanghai。
- 开始、暂停、继续、收口和上下文更新先写 IndexedDB（不可用时回退 `localStorage`），联网后按序同步；在线开始请求与离线队列共享同一个启动幂等键，避免响应未知时重复创建；`BroadcastChannel` 将快照传播到其他标签页。
- 活动页和 App Shell 每 15 秒发送设备心跳；心跳不改写命令 CAS 使用的 `updatedAt`，底部共享工具栏据此显示本设备或另一设备状态。
