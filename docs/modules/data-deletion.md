# 本人数据回收站与删除

## 边界

入口为 `/settings/data` 的“回收站与删除”。实现默认关闭，启用及验收状态见[数据生命周期任务](../../tasks/backlog/0041-data-lifecycle.md)。
Web 只预览、登记和控制删除意图，物理文件与数据库清理由独立进程执行，不提供 shell、备份恢复或服务器命令入口。
旧 `DataJob` 删除预览仍不执行删除，不能升级或冒充新的持久删除意图。

## 范围与确认

- 账户范围只处理本人数据；工作区范围要求当前 Owner，仍不能删除其他成员的私有记录。
- 对象回收站支持本人知识卡片、错题、任务、资料和知识点，要求对象所在工作区的有效成员身份。
- 计划逐项绑定主键、内容版本、授权状态与数据模型，不以相同计数代替相同对象。
- 外键和已登记软引用必须闭合；未知归属、其他成员引用、仍受保留规则保护的运维/Coach 协作引用、未解散挑战、活跃学习或后台任务等均阻断。
- 同一附件存储身份存在多个 metadata 引用时阻断；不通过删除其中一条 metadata 猜测文件归属。
- 用户需近期重新验证、核对当前目标与影响计数，并输入明确确认词。请求幂等键与预览指纹绑定。

账户/工作区请求有 24 小时冷静期；对象回收站有 30 天恢复期。期限由数据库时钟计算，客户端不能指定或缩短。
未到期不执行物理删除。回收站恢复不复制正文，而是解除原对象的可见性和写入栅栏。

## 冻结与可见性

`DataDeletionFence` 逐对象保护普通查询及写入。建立栅栏与普通写事务使用一致锁协议；现有记录及新建外键/软引用不能越过冻结。
Web 查询保留原 owner/租户条件，并排除被冻结对象、嵌套关系及关系计数。交互事务使用原事务连接，批次查询不额外占用连接；可见性代次变化时不交付旧响应。
知识画布的原生 SQL 显式接入同一栅栏，在节点、边、聚合计数和分页之前过滤，查询前后核对代次；不能仅在返回 DTO 时抹去标题。

搜索分区与标题文档同样受冻结保护。查看者删除不沿副本反向删除他人源；源所有者删除仅纳入类型、源外键与分区工作区绑定一致的精确副本。
重建保留被冻结旧副本的 rowHash/fence，排除冻结源并仅回收未冻结旧代次。跨工作区迁移后的旧搜索副本可以精确清除，其他模型或旧授权引用仍按原规则阻断。详见[工作区持久搜索](workspace-search.md)。

登录会话、一次性认证 token 和本人 `AUTH_` 安全审计属于账户删除计划明确声明的可变安全清理集合，不冻结登录或重新验证。
最终事务在账户行锁下按本人 ID 统一撤销，计数单独写入最小账本。密码、凭据、正文和完整文件路径不进入删除回执。
账户与成员授权版本仍需重验；恢复旧角色或重新加入不会自动激活旧删除请求。

## 执行与恢复

删除意图不对待删除的 User/Workspace 建外键，避免根对象清除同时销毁执行状态或审计。
独立消费者具备租约代次、持久退避、最大尝试预算、死信状态和人工重试。取消与开始不可逆处理互斥；越过不可逆点后不能用“取消”掩盖已删除文件。

文件流程为：校验私有根和同一文件身份 → 持久文件意图 → 精确 unlink → 目录 fsync → 文件回执。
只处理计划中的随机存储名；拒绝穿越、软链接、硬链接和 hash/size 不一致，不扫描或清理历史 orphan。
文件 IO 不伪称数据库事务。进程中断后以已提交文件意图判断缺失状态，新租约恢复处理，旧租约不能提交。
源记录删除、最小账本和成功状态在同一数据库事务中提交，缺失步骤不能被写成成功。

恢复期过后若授权版本变化，用户可近期重新验证并重试。只允许重新绑定内容与身份完全未变的冻结集合，不增加对象、不延长恢复期。
关闭新请求和消费者不阻止合法取消或恢复；保留可见性保护，不能回退到不理解栅栏的旧读取实现。

## 删除账本与历史备份

账本保留必要 scope、资源身份、随机文件身份、hash、时间和计数，不保留学习正文、源认证凭据或可复原 secret。
哈希链必须绑定从可信源独立取得的 head；文件内自带的可重算 hash 不是授权。
历史备份只能先恢复到隔离、不对外服务的目标，再按备份内账本的序号与 head 核对可信源链，重放快照缺失的后缀；水位与 dump hash 绑定。不能按删除时间过滤：事务可能先记录时间、在备份快照之后才提交。重新按原 owner/scope 核验旧引用，不能借恢复删除他人数据。
重放失败或归属不明时保持恢复目标不可发布；重放已完成的条目幂等。生产恢复仍需独立的 SRE 确认与交付证据。

## 回执与验证

本人会话可读取意图的最小状态。账户删除后，当前页可用高熵回执凭据通过同源 POST 继续读取最小回执；它不授予控制、正文或文件下载权，完成后最多保留一小时访问期。
凭据只在当前页面内存和 POST body 中传递，不进入 URL、日志或浏览器持久存储。

验收覆盖规则、完整 migration ledger/hash、双用户/工作区、冻结、期限、租约、并发、真实强杀、文件/SQL 一致性、历史备份重放和真实浏览器。
本地机制验证不证明生产恢复、Release、长期容量或综合平台门禁完成。
