# 反假学习

## 目标

识别“看起来学了很久，但没有真正吸收”的情况。

## 触发

- 每次计时结束。
- 每晚复盘。
- 周复盘。

## 检查问题

- 这段时间产出了什么？
- 能不能用自己的话讲出来？
- 有没有做题验证？
- 有没有形成笔记或错题？
- 下次复习什么？

## 低转化学习

- 只看课，没有输出。
- 只抄笔记，没有理解。
- 只刷题，没有复盘错因。
- 计时很长，但任务没有推进。

## 处理

- 标记为低转化学习。
- 要求补一个最小输出。
- 纳入周报统计。
- 收口最小产出必须由用户真实填写；空白或不足 4 个字符时就地提示，前端不得用占位文案代替学习事实。
- 用户可以承认低转化并结束或显式加入计划收件箱，但系统不能把补救建议自动写成正式任务。
- 知识卡片、错题或复测只有在对应实体成功创建、归属与本次学习上下文通过服务端校验后，才计入本次 Session 的证据回执；不能仅凭前端选择伪造产出标志。
- 创建成功但回写中断时必须保留同一重试身份，重复提交只恢复回写，不得生成重复学习证据。
