# 今日作战台

## 目标

今日作战台是每天打开 AreaForge 的第一屏，目标是让用户立刻知道今天要做什么、当前风险是什么、下一步动作是什么。

## 展示内容

- 今日日期。
- 当前工作区下一场未完成模拟考试倒计时；未安排时显示空态。
- 当前工作区目标考试日倒计时；未设置时不触发冲刺窗口。
- 今日学习总时长。
- 有效学习时长。
- 今日任务完成率。
- 当前连续打卡天数。
- 当前阶段名称。
- 当前风险等级。
- 今日鞭策文案。
- 快速开始学习计时。

所有时长、科目分布、完成率、趋势和风险必须来自当前工作区的真实记录或可追踪规则。无样本时显示“尚无记录”或“未设置”，不生成固定分钟数、积分、比例或趋势线。

## 当前闭环能力

- 今日页展示“行动执行 -> 证据接力 -> 每日复盘”三阶段进度，只从当日 session、证据和复盘事实派生。
- 最近一次已完成学习留下的下一动作会形成断点续学入口；当前存在活动或恢复状态时不展示该入口。
- 推荐卡展示来源原因，并允许记录“适合当前节奏”或“暂时换一项”；后者重新计算推荐，不改写正式任务。
- 有有效学习事实时每日复盘动作显示“结束学习并复盘”，复盘完成后显示“今日已闭环”。
- 自由学习、专项复测和模拟考试完成页重新读取今日推荐，有候选时可直接“继续下一项”，否则返回今日或原来源。

## 信息优先级

第一优先级：

- 当前推荐任务。
- 开始计时。
- 风险等级。

第二优先级：

- 今日指标。
- 欠账任务。
- 考纲进度概览。

第三优先级：

- 错题提醒。
- 复盘提醒。
- 阶段称号。

## 状态影响

- 正常推进：展示完整作战台。
- 连续高完成：突出连胜和阶段突破。
- 断签警报：突出欠账和恢复动作。
- 恢复模式：只展示最小任务。
- 冲刺模式：前置真题、模拟、错题。
