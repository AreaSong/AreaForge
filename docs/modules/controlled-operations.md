# 受控运维

## 边界

系统设置中的受控运维只对平台 Operator 开放。Workspace Owner 不因此获得服务器权限。
Web 只登记意图、确认、审批和控制请求，不能启动服务器进程，也不能读取 root 配置、签名私钥、备份或原始 journal。

六个操作是封闭白名单：检查 Release、备份计划预览、健康诊断、应用 Release、固定目标回滚、维护 admission 屏障。
备份计划预览始终不执行备份。维护屏障只阻止新的领取，不意味着正在运行的进程已经停止、队列排空或 timer 停止。

## 冻结与执行

创建请求前由独立执行器生成脱敏前态。创建时将完整 expected-before、不可变 Release/manifest/镜像身份、固定 rollback 来源、原请求 hash/nonce/初始修订和旧 updater wire 一起冻结到现有 operation JSON。
外层请求使用不同的 hash domain，避免将最终 hash 嵌入自身；消费时只比较和拒绝，不重算新的批准、目标或有效期。旧 tag-only 请求不能被新执行器消费。

用户重新验证身份后确认和审批。root 执行器重验 Operator、绑定、TTL 和前态；生产适配器继续使用既有 updater 的签名、checksum、digest、两次前态比较、备份和固定回滚门禁。
执行器和生产入口分别默认关闭。合成模式显示 `local_fixture`，不代表真实备份、部署、迁移或生产健康。

## 停止与恢复

运行中的取消、挂起或过期保留租约，直到执行器确认已停止。等待期间不能恢复或再次领取；心跳不改变用户控制修订。
新的取消意图不能被较早的挂起回执覆盖。已经完成的动作记录真实结果，不伪称“取消成功”能撤销副作用。

跨进程锁被子进程继承；父进程被强杀时，仍在执行的子进程继续持锁。请求桥接与阶段记录先写入、fsync 并不可覆盖发布，再进入下一阶段。
原始 journal 与脱敏投影使用不同 hash。全作用域 admission 同时校验其他请求的数据库锚，合法前缀截断也不能绕过待对账屏障。
数据库中的 root 桥接登记还能发现整份 journal 缺失；已证明从未领取的准备记录不会误阻塞后续请求，过期的未运行请求只记录过期，不执行动作。

明确零副作用拒绝是普通失败；未知副作用停止消费并需要对账，不自动重复执行。已持久化终态但数据库写回失败时只恢复回执；恢复 claim 与终态来源在同一数据库事务绑定，重复恢复中断不丢失已确定事实。

## 用户可见证据

请求卡片展示绑定环境、目标、执行阶段、停止等待和待对账状态。阶段历史只返回经过 schema/hash 校验的脱敏投影及原始证据 hash，不返回私有路径、命令、凭据或原始输出。
网络响应丢失后复用同一冻结意图与幂等键，不生成第二次执行。
