# 错题学习证据闭环

## 目标

错题不是静态摘录，而是可反复经历“看题、独立作答、揭示答案、自评、排期、追踪趋势”的学习对象。

## 当前实现

- 新建错题要求标题、完整题面、明确错因和正确思路；标准答案与错因补充说明可选。历史错题继续可读，补全前不能进入复习或新增作答。
- `POST /api/mistakes/:id/attempts` 保存独立文字或纸上/口头作答、自评结果、可选时长和复盘备注。独立作答不修改统一复习排期。
- `/knowledge/mistakes/practice` 提供独立练习模式：先按当前筛选抽题，再逐题完成作答、揭示标准答案与正确思路、选择结果并保存备注。混合模式按“到期 -> 最近一次结果为未通过 -> 其他完整错题”排序；到期和失败层内部按日期/最近作答时间稳定排序，题量最多 50 题。历史记录逐题写入 `MistakeAttempt`，练习结束只给出进入详情确认排期的建议，不自动物化或调整 `ReviewSchedule`。
- 练习结果页保留每题的结果与详情入口；“再来一轮”生成新的会话幂等范围，重复提交同一请求只复用既有作答记录，变化后的同键请求返回冲突。
- 错题统一复习先作答再揭示答案，确认事务同时创建 `ReviewEvent` 和一对一 `MistakeAttempt`。更正只追加事件，不改写历史作答。
- `PATCH /api/mistakes/:id/links` 以 `expectedUpdatedAt` 做乐观并发，维护知识卡片和学习资料关系；目标对象必须属于当前活动工作区。
- 模拟失分只打开预填表单；创建成功后在同一事务写入 `SimulationLossItem.mistakeId`。重复转换返回已有错题或 409，不生成不完整记录。
- 题目附件继续通过学习资料关联和既有私有下载鉴权，不新增文件存储路径。

## 页面契约

- 列表显示题面摘要、作答总数、最近结果和排期状态，并保留科目、考纲、错因与复习筛选；顶部提供错题总数、今日到期、最近通过率和最近失败概览。
- 详情显示完整题面、标准答案、正确思路、错因说明、独立作答、作答时间线、复习历史及笔记/资料关系；作答历史同时汇总最近通过率、连续通过、最近失败和最近结果。
- 详情中的独立作答允许在揭示后重新核对答案，保留当前结果与备注；归档错题或只读工作区不再接受新的作答写入。
- 复习排期提供明天、3 天后和自定义日期快捷选择；快捷建议只更新待确认日期，用户点击确认后才写入现有 `ReviewSchedule`，不引入第二套排期规则。
- 专注收口创建表单与普通创建使用同一必填规则；模拟失分入口复用普通创建 Drawer。

## 非目标

账户导出、OCR、AI 批改、自动判分、完整题库和第二套排期规则不在本次范围。生产 migration、部署和 Release 需要独立确认。
