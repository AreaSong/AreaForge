# 专注计时 UX

## 页面职责

`/focus` 是独立一级入口，只承载自由学习：先选择科目，进入唯一活动计时器；复测和模拟考试不能从这里选择或启动。如果已有任意类型活动，无论打开多少个计时器页都回到同一个活动来源页。它不承载学习安排编辑、知识列表或每日复盘。页面按活动事实在以下状态间切换：

```text
专注计时 -> 学习收口 -> 低转化补救或证据接力 -> 完成摘要 -> 今日下一行动
```

浏览器返回或“返回来源 · 计时继续”只离开页面，不暂停、不结束活动。进入 `CLOSING` 后，收口表单由公共固定窗口承载；用户可以继续浏览其他页面，窗口在底部共享栏中保留，不强制回到来源页。完成摘要以“回到今日，查看下一行动”为主操作；当来源不是今日时，仍可通过次操作返回白名单 `returnTo` 指向的计划或任务详情。

## 专注计时

桌面使用完整工作区，主区显示数字计时和指针式秒表视觉，右侧显示科目以及可选的后置上下文；不再使用统一窄内容容器。移动端改为单列，计时器和两个当前可执行命令保持首要。

显示：

- 当前科目。
- 当前任务（可选，开始后或收口时补充）。
- 当前知识点/考纲节点（可选，开始后或收口时补充）。
- 已学习时长。
- 暂停、继续、结束按钮。

目标时长只到点提醒，不自动结束，也不把超时判为失败。其他区域弱化，避免干扰。

专项复测和模拟考试使用各自工作台的配置对象和专用计时器，不复用自由学习的启动表单；公共工具栏只展示当前唯一活动，不提供新建第二个活动的入口。

## 暂停

暂停时保持专注区域，但明确显示“已暂停”。

## 学习收口

点击“结束并收口”后活动进入 `CLOSING`，公共收口窗口在当前页面打开；移动端按事实摘要、表单、保存操作顺序单列显示。用户可以继续浏览其他页面，收口窗口会保留在底部共享栏；未完成收口只能最小化，不能直接关闭。收口记录：

- 结果：达成、部分达成、未达成。
- 理解程度：清晰、基本理解、模糊、不会。
- 真实最小产出，至少 4 个字符。
- 任务去向：完成任务、继续推进、遇到阻塞。
- 下一动作；遇到阻塞时改为阻塞原因和恢复位置。

空白或过短的最小产出必须就地报错，前端不得自动生成“本次最小产出”等占位事实。收口草稿继续保留 24 小时；保存成功后才清除。

## 低转化与完成

- 低转化先保存 session 事实，再展示可解释原因。
- 主操作是补一个最小产出，次操作是加入计划收件箱。
- 用户可以承认低转化并结束；该动作不会伪造有效学习。
- 非低转化进入证据接力；知识卡片、错题和复测使用当前页面内嵌表单，不离开专注流程。
- 内嵌表单固定继承当前科目；知识卡片同时继承任务和考纲节点，错题继承考纲节点，只有已关联考纲节点时才能记录复测。
- 证据实体创建成功后，服务端再次校验用户、工作区、科目、任务和考纲上下文，再写入 Session 证据回执；知识卡片和错题同时更新 `producedNote` / `producedMistake`。
- 实体创建与 Session 回写使用可重试命令身份。若创建成功但回写中断，草稿和命令身份继续保留，显式重试不得重复创建实体。
- 证据接力阶段和三个表单草稿可在刷新后恢复；用户显式完成证据接力后才清除阶段标记。
- 最终完成摘要展示实际时长、转化结果、服务端任务状态和本次已保存证据；主操作回到今日刷新下一行动，非今日来源保留“返回原页面”次操作。用户也可以在当前页面之外通过公共窗口继续收口，不需要被强制跳回活动来源。

## 本地优先与断网

- 开始、暂停、继续和结束命令先写入 IndexedDB，浏览器不支持时回退到 `localStorage`；本地快照只表示“待同步”，不冒充服务端完成。
- 同一用户的同步队列使用单飞锁，多个标签页或 `online` 事件不会并发重放同一批命令；不可重试的 4xx 会阻塞并等待人工处理，网络错误保留为待同步。
- 断网结束后先展示本地完成摘要；联网同步到真实 session 后，系统会把证据接力标记迁移到服务端 session，再进入真实证据表单。证据 API 不接受本地 session ID。

结束计时不能只停表，必须把学习转化为记录。
