# 应用壳层与工作台布局

本文定义 AreaForge 登录后界面的目标信息架构、页面布局和跳转契约，也是当前 UI 重构的评审基线。公共壳层、五个一级业务入口、独立开始学习计时、每日复盘接力、知识统一复习、“周期报告 -> 学习安排收件箱 -> 阶段跟踪”以及“模拟考试 -> 失分分析 -> 补救入箱 -> 阶段调整”闭环已按本文分批落地。设置保留在侧栏底部工具区，不与五个业务入口平级。共享设计令牌与组件语义见 `docs/ux/shared-ui-foundations.md`，功能与实现状态以 `docs/development/feature-traceability.md` 为准，路由清单见 `docs/ux/site-navigation.md`。

## 设计目标

界面首先服务于“决定下一步并完成学习闭环”，而不是同时展示所有能力。

- 充分使用可用宽度，但不让长文本无限拉宽。
- 一级导航稳定回答“我在哪个工作台”，页面标题回答“我正在处理什么”。
- 每个页面只有一个视觉上最强的主操作；其他命令降为次级按钮、菜单或行内动作。
- 状态、导航、筛选、页签和创建命令使用不同的视觉语义，不互相伪装。
- 列表选择、筛选条件和来源页可恢复；详情完成后回到用户进入时的上下文。
- 桌面端强调并排查看和快速操作，移动端强调单列任务流，不简单压缩桌面布局。

## 全局 App Shell

### 桌面结构

```text
┌──────────────┬──────────────────────────────────────────────────────────┐
│ 一级工作台   │ 顶部共享：状态 / 面包屑 / 功能 / AI                      │
│              ├──────────────────────┬───────────────────────────────────┤
│ 开始学习     │ 二级导航（从属）      │ 三级内容：当前列表 / 当前对象     │
│ 今日         │                      │                                   │
│ 知识         │                      │                                   │
│ 检验         │                      │                                   │
│ 路线         │                      │                                   │
│              ├──────────────────────┴───────────────────────────────────┤
│ 设置 / 账户  │ 底部共享：计时 / 当前页面 / 来源 / 同步 / 设备状态         │
└──────────────┴──────────────────────────────────────────────────────────┘
```

- Shell 占满视口宽度，不设置全局 `max-w-*`；侧栏固定宽度，内容区自适应。
- 一级导航独占左侧全高；右侧顶部共享区、底部共享区横跨二级导航和三级内容。
- 右侧中部才拆分为二级导航与三级内容；二级视觉权重低于一级，二级标题只标记所属工作台，三级只呈现当前列表或对象。
- 顶部共享栏右侧固定提供全局 AI 助手；面包屑右侧直接平铺当前二级视图的常用功能入口，不复制二级导航。超过三个入口或窄屏空间不足时，只将低频入口收进“更多”。
- “今日状态”汇总计划、专注、复习、复盘和风险；展开后可查看分项及唯一建议动作，不显示五个并列状态灯。
- 快捷创建只承担跨工作台创建：任务、知识卡片、错题、资料、考纲节点。页面自身的创建动作仍由页面主按钮承担。
- 设置、账户和退出位于侧栏底部，与五个一级业务入口保持工具层级。
- 内容区不统一限制宽度；具体宽度由页面模板决定。

### 移动结构

```text
┌─────────────────────────────┐
│ 页面标题       状态  +  恢复 │
├─────────────────────────────┤
│ 局部页签 / 筛选              │
├─────────────────────────────┤
│                             │
│ 单列页面内容                 │
│                             │
├─────────────────────────────┤
│ 开始学习 今日 知识 检验 路线 │
└─────────────────────────────┘
```

- 窄屏底部导航保留五个一级业务入口并提供设置工具入口；空间不足时允许横向滚动或收进菜单，不改变 canonical 层级，也不新增移动端独立导航体系。
- 局部导航横向滚动或收进菜单，不强制等宽挤入一行；移动端功能入口继续从共享面包屑右侧进入，并允许换行或收进“更多”。
- 列表与详情改为前后页；返回时恢复滚动位置和筛选。
- 页面主操作可在底部形成安全区工具栏，但不能遮挡表单错误、分页和底部导航。

## 视觉与控件职责

| 类型 | 视觉职责 | 行为约束 |
|---|---|---|
| 一级导航 | 工作台切换 | 开始学习、今日、知识、检验、路线 |
| 二级导航 | 一级工作台下的稳定业务视图 | 使用从属侧栏或页签，不与一级平级，不承担创建命令 |
| 三级内容 | 当前列表或对象 | 展示业务内容，不重复渲染二级导航 |
| 页面主操作 | 完成本页最重要的动作 | 每页最多一个高强调按钮 |
| 次级操作 | 编辑、导入、导出、批量处理 | 普通按钮或更多菜单 |
| 筛选与搜索 | 改变当前结果集 | 尽量写入 URL，刷新和返回后可恢复 |
| 状态与风险 | 描述事实和紧迫度 | 不伪装成导航；需要时附一个建议动作 |
| 对象链接 | 打开任务、卡片、错题等详情 | 文本链接或整行点击，不使用主按钮样式 |

页面标题区统一包含：面包屑或返回入口、标题和必要的状态摘要；需要执行命令的页面至多放一个主操作。说明性长文不常驻标题区。

## 四种页面模板

### `dashboard-wide`

用于今日、计划、知识概览、报告和阶段概览。内容区使用填满可用区域的宽屏栅格，不设置统一最大宽度，两侧只保留响应式安全边距；其中的长文本块单独限制可读行宽。

- 首屏先放决策信息和主操作，再放趋势或补充数据。
- 主列承载当前队列或关键事实；辅列承载风险、进度和下一节点。
- 卡片只用于独立、可重复或可点击对象，不把整段页面套进卡片。

### `split-view`

用于任务、收件箱、考纲、卡片、错题、资料、复习排期和模拟考试。

- 桌面为“筛选栏 + 列表 + 详情”，列表与详情可独立滚动。
- 选中对象写入路由或稳定 URL；刷新后仍能恢复详情。
- 移动端先显示列表，选择后进入详情页；详情页提供明确返回来源。

### `content-focus`

用于每日复盘、设置、创建和编辑表单。正文保持适合阅读与填写的宽度，通常为 `720-960px`，但背景和页面带仍占满内容区。

- 表单按任务步骤分组，不使用多层嵌套卡片。
- 保存区稳定，校验错误就近展示。
- 离开未保存内容时必须确认；保存后回到来源或对应详情。

### `workspace-full`

用于关联画布、专注、资料预览等需要空间或沉浸的页面。

- 使用整个可用区域，不套通用内容容器。
- 工具栏、检查器和画布分别占据稳定区域。
- 专注页隐藏普通 Shell；画布和预览保留最小导航与退出路径。

## 工作台导航

| 一级工作台 | 默认入口 | 二级导航 | 核心问题 |
|---|---|---|---|
| 开始学习 | `/focus` | 无 | 现在直接开始哪一科？ |
| 今日 | `/today` | 今日行动、完成情况和闭环 | 今天我现在做什么？ |
| 知识 | `/knowledge` | 概览、知识点、考纲、学习资料、笔记、错题、复习；工具：关系图、导入 | 我学了什么，哪里薄弱？ |
| 检验 | `/test` | 专项复测、模拟考试 | 我是否真正掌握并能在检验中应用？ |
| 路线 | `/roadmap` | 学习安排、阶段、周期报告 | 长期结果如何形成可执行路线？ |
| 设置（工具区） | `/settings` | 工作区、档案、偏好、AI、系统 | 系统如何按我的边界运行？ |

知识中的“关系图”和“导入”是低频工具，不与日常视图并列争夺首屏位置。阶段与周期报告属于路线工作台的二级视图，模拟考试属于检验；周期报告中的“当前/历史”和“周/月”分别是视图与周期筛选，不扩充成更多一级入口。确认中心是共享工作流入口，不增加新的一级业务导航。

## 页面契约

### 今日与路线

| 页面 | 布局 | 核心模块 | 主操作 | 进入与离开 |
|---|---|---|---|---|
| `/today` | `dashboard-wide` | 下一行动、推荐项之外的任务/复习/错题后续队列、今日完成摘要、风险/欠账摘要 | 开始推荐行动 | 当前推荐不在后续队列重复出现；无任务快捷计时收进“临时专注”备用入口；任务进入详情，复习进入快速复习；活动结束回到本页并刷新状态 |
| `/roadmap/allocation` | `dashboard-wide` + 桌面 `split-view` | 顶部搜索与科目/状态筛选、移动日期带或桌面七日任务列、欠账、选中任务详情 | 新建任务 | 无详情时桌面只显示七日列，移动端使用日期带，避免重复导航；投入草稿入口统计全部未被替代的待处理项；新建任务使用 Drawer，成功后进入新任务详情并保留日期与筛选来源；桌面选中任务写入 `taskId` 并在右侧展开详情，关闭后保留日期与筛选；移动端进入 `/roadmap/allocation/tasks/[taskId]` |
| `/roadmap/allocation/tasks/[taskId]` | 移动端独立详情；桌面详情内容复用于投入安排分栏 | 任务目标、状态、依赖、里程碑、关联知识、活动记录 | 开始或继续专注 | 主操作与任务状态前置在标题区，编辑保持次级；从今日进入时携带 `returnTo=/today`，从投入安排进入时保留安排上下文；启动专注继续传递该来源；返回时恢复日期、筛选、滚动位置和任务焦点 |
| `/roadmap/allocation/drafts` | `split-view` | 来源与状态筛选、草稿列表、预览 | 补全并转换或打开任务 | 每个状态只保留一个主接力：待处理草稿进入补全/确认，已转换项打开任务，查看历史退为次级；详情和已转换任务保留当前状态、稳定引用及上一层来源；空状态提供返回待处理草稿或今日下一行动的出口 |
| `/roadmap/allocation/drafts/[itemId]` | `split-view` 的详情态 | 人类可读的来源、建议内容、任务字段、驳回原因；日期按上海学习日显示 | 转为任务 | 日期可精确选择，也可用“今天 / 明天”快速安排；快捷选择只更新本地草稿，转换仍需显式确认；成功进入带当前投入草稿筛选来源的任务详情，驳回、替代版本、稳定依赖和阶段入口均保留原上下文 |
| `/focus` | `workspace-full` | 全宽计时、任务上下文、整页收口、低转化补救、内嵌证据接力、完成摘要 | 结束并收口 | 隐藏普通 Shell；离开视图明确提示计时继续；空白产出不能保存且不得自动代填；卡片、错题、复测在当前流程创建并经服务端校验后回写 Session；低转化补救进入收件箱时保留当前专注详情作为返回来源；完成摘要以回到今日查看下一行动为主操作，非今日来源保留返回原页面次操作 |

### 知识

| 页面 | 布局 | 核心模块 | 主操作 | 进入与离开 |
|---|---|---|---|---|
| `/knowledge` | `dashboard-wide` | 待复习、薄弱考点、最近卡片/错题、资料与导入摘要 | 开始待复习 | 各摘要进入对应列表并带上筛选上下文 |
| `/knowledge/syllabi` | `split-view` | 统一搜索、科目/状态/地图/行动筛选、作战地图、考纲树、节点详情与掌握证明 | 新建考纲节点 | 首屏先呈现作战地图和节点行动；长期遗忘风险只保留紧凑摘要并置于地图之后，完整风险原因、证据与下一步动作按需展开。地图标题区是唯一创建入口，Drawer 同时承载单节点创建和 Markdown 批量导入；单节点成功进入详情，批量导入留在地图并显示摘要 |
| `/knowledge/syllabi/[nodeId]` | `detail-focus` | 节点身份、状态/风险摘要、唯一下一行动、统一复习排期、掌握证据与复测历史 | 按节点下一行动推进 | 首屏先给节点行动；安排学习任务会带入科目和考纲节点，复测、证据与复测历史保留为独立视图；编辑、归档和版本冲突属于管理动作 |
| `/knowledge/notes` | `split-view` | 统一搜索、科目/节点/掌握/复习筛选、卡片列表、卡片详情 | 新建卡片 | 列表标题区是唯一创建入口，Drawer 创建成功后进入 `/knowledge/notes/[noteId]` 并保留列表来源 |
| `/knowledge/mistakes` | `split-view` | 统一搜索、科目/节点/错因/复习筛选、错题列表、复测与掌握状态 | 记录错题 | 列表标题区是唯一创建入口，Drawer 创建成功后进入 `/knowledge/mistakes/[mistakeId]`；复测后停留在当前对象 |
| `/knowledge/resources` | `dashboard-wide` | 资料状态、真实科目筛选、当前资料列表；归档资料为折叠次级区 | 添加资料 | 页头是唯一创建入口，右侧抽屉切换文件上传与 HTTPS 外链；单个外链成功进入详情，批量文件上传留在列表显示结果；未完成上传或重复决策保留恢复入口 |
| `/knowledge/resources/[resourceId]` | `detail-focus` | 资料事实、学习关联、首次复习日期；整理时才展开编辑表单 | 私有预览、下载或打开链接 | 消费资料是页头主操作；关联任务是独立下一行动；预览与关联对象继续携带当前详情及上游来源 |
| `/knowledge/resources/[resourceId]/preview` | `workspace-full` | 文件内容与资料元数据 | 返回资料详情 | 返回含上游来源的资料详情；不在预览层堆放编辑表单 |
| `/knowledge/reviews` | `split-view` | 到期/逾期队列、对象摘要、复习进度 | 开始下一项 | 进入 `/knowledge/reviews/[scheduleId]/run?returnTo=...`，完成后推进下一项 |
| `/knowledge/reviews/[scheduleId]/run` | `workspace-full` | 复习对象、回忆提示、确认/纠正 | 完成本次复习 | 完成后返回队列并保留进度；可继续下一项 |

统一复习当前实现契约：

- `/knowledge` 首屏只保留一个当前下一行动，页头不重复同一操作；到期复习优先于薄弱节点、待整理资料与最近导入，最近卡片和错题作为学习证据直接回到对象详情。
- `/knowledge/reviews` 使用单一队列和状态分段，不再同时堆叠四块列表；顶部展示今日进度、逾期、今日到期和预计剩余时间，默认聚焦第一项可执行复习，后续队列不重复该项。
- 已转正式任务的复习只保留一个“打开任务”接力，并携带复习队列来源；排期详情按“下一行动 → 对象核验 → 排期管理 → 事件历史”分层，以“开始快速复习”为活动排期的主操作，暂停、恢复和历史更正属于管理动作，状态更新异常仍返回当前来源。
- 队列、排期详情和完成态只展示中文对象类型、结果与任务状态，不暴露 `NOTE`、`PASSED`、`ACTIVE` 等内部枚举。
- `/knowledge/reviews/[scheduleId]/run` 保留本地草稿、CAS、多标签页互斥和幂等确认；完成态先用统一下一行动承接“继续下一项”或按 `returnTo` 返回来源，再展示本次结果、连续通过变化和下次日期；对象详情与复习历史各只保留一个带上下文的次级入口，排期/对象失效时也返回原来源。
- 卡片、错题、资料和考纲节点详情继续作为对象源事实，并共用“返回来源、对象身份、状态摘要、下一行动、当前主操作”的页头后内容骨架：存在可执行的到期排期时复习优先；资料则以私有预览、下载或打开链接为消费主操作；归档保持次级管理。卡片与错题显示复习历史和下次到期，考纲节点显示统一排期、掌握证据与复测历史；各自的正文、独立重做和证据分段不被强行合并。
- 卡片详情的下一行动在无排期时引导到首次复习日期，有活动排期时进入排期详情，到期时提示从页头开始复习；错题详情在未补全时先引导补全，独立重做揭示正确思路后再引导首次排期。只读或归档对象只显示状态，不继续提供学习写入口。
- 资料详情默认展示只读事实与可跳转的任务、卡片、错题和考纲关联，显式点击“整理资料”后才展开元数据与多选关联表单；本地存在未保存草稿时自动恢复编辑态。关联任务或创建任务作为独立下一行动，不与资料消费按钮并列竞争；归档资料的下一行动仅提示恢复后再安排学习。
- 资料列表首屏不常驻创建表单，只展示资料状态、科目筛选和当前资料；筛选参数 `subjectId` 直接约束列表结果。页头“添加资料”是唯一创建入口，抽屉内切换文件与 HTTPS 外链；未完成上传、重复文件决策和草稿恢复仍在列表页提供显式接力，上传安全、幂等与冲突处理语义不变。列表使用中文来源、类型、科目与整理状态，归档资料保持折叠次级区。
- 知识工作台顶部搜索是卡片、错题、考纲和资料的唯一搜索入口；页面内工具栏只管理各自业务筛选。搜索词与筛选写入 URL，刷新、详情返回和跨知识页切换后可以恢复；清除页面筛选保留搜索词，清除搜索则保留当前页面允许的业务筛选。原始列表为空与当前搜索/筛选无结果必须使用不同空状态。
- 知识列表项统一按“科目与状态标签 -> 标题 -> 两行内摘要 -> 来源/更新时间等元数据 -> 打开详情”组织。列表不重复承载对象详情已有的编辑表单：错题编辑进入详情，卡片附件管理默认折叠；考纲节点只在摘要层保留快速状态更新，掌握证明、证据引用和复测表单放入显式折叠区。资料沿用同一状态标签和详情动作层级。
- 卡片、错题和考纲地图同样不在主内容区常驻创建表单；各自标题区保留一个创建按钮，`?create=1` 与 App Shell 快捷创建直接打开同一 Drawer。关闭 Drawer 只隐藏表单，不清除本机草稿；单对象创建成功进入新对象详情并携带列表来源，Markdown 或多文件等批量创建留在原列表显示结果摘要。
- `/knowledge/syllabi` 首屏优先保证作战地图、节点树和下一行动可见；“考纲遗忘风险”使用默认收起的紧凑摘要，展开后仍保留风险来源、证据新鲜度、重点科目和下一步动作，且不改变只读与需确认边界。
- `/knowledge/syllabi/[nodeId]` 首屏先显示节点当前下一行动：无统一排期时可直接进入带科目和节点上下文的最小任务创建，已有排期时进入排期管理，到期复测仍由页头主操作承接。概览只保留投入、风险和排期事实，掌握证据与复测历史通过独立视图访问。
- 知识概览、复习队列、排期详情和快速复习进入对象详情时携带安全 `returnTo`；对象再次发起快速复习时保留该上游来源，完成后可先回对象核验证据，再回原工作台。
| `/knowledge/canvas` | `workspace-full` | 关系画布、搜索、图例、对象检查器 | 聚焦选中对象 | 从对象详情带焦点进入；关闭检查器或返回来源，不改变对象事实 |
| `/knowledge/imports` | `dashboard-wide` | 默认展示批次状态与历史；`mode=import` 为内容/差异/确认工作态，`mode=export` 为独立导出工作态 | 开始导入 | 总览仅保留一个导入主操作；草稿自动恢复到导入工作态；原子确认后进入 `/knowledge/imports/[importId]` |
| `/knowledge/imports/[importId]` | `dashboard-wide` | 中文应用/跳过摘要、导入明细；协议、哈希与规范化源折叠为技术信息 | 查看考纲结果 | 下载与归档为次级管理；可返回导入历史 |

卡片、错题、资料、考纲节点及导入批次的动态详情路由沿用同类列表/详情契约，不另建一套视觉结构。

学习树导入工作台保持“总览 -> 内容 -> 差异 -> 原子确认 -> 批次结果 -> 考纲核验”闭环。模板和 AI 草稿只在导入工作态出现，导出不与导入表单竞争首屏；preview 继续不写业务数据，只有显式 confirm 才写入。中断、登录失效或冲突时保留 Markdown 与映射，必须重新预览最新差异后才能再次确认。

周期报告当前实现契约：

- 第一屏只前置唯一最大短板、规则建议的下周期焦点和一个确认主操作；执行指标、科目投入与判断原因作为证据下沉。
- 页面明确区分客观执行事实、规则判断、待确认草稿和已冻结决策；报告或本地规则不显示为自动生效的权威结论。
- 确认报告后，主接力先进入 `/roadmap/allocation/drafts` 逐项处理投入草稿；若同时生成阶段建议，再进入 `/roadmap/stages` 独立确认。报告确认不修改现有任务或当前阶段。
- 已冻结结果明确区分新增、复用和零草稿：有新增时处理新草稿，仅复用时查看现有收件箱，零新增且零复用时不显示虚假的收件箱主操作。
- 历史详情只回放当时冻结的事实、结论、决策与入箱汇总，不允许再次应用，也不根据汇总数量推断每条草稿当前状态。

路线中的阶段视图当前实现契约：

- `/roadmap/stages` 第一屏只给一个下一行动：有待确认草稿时先审阅建议；没有生效路线时先创建阶段；否则检查里程碑或趋势。
- 当前生效路线、待确认阶段建议和最近已应用/已拒绝结果分区展示。只有阶段草稿确认后才更新生效路线，派生任务仍先进入学习安排收件箱。
- 概览展示剩余时间与进行中里程碑数量；里程碑的归档状态不冒充完成进度。
- `/roadmap/stages/trend` 把最高风险、原因、建议和处理入口前置，指标、每日趋势与科目投入作为判断证据下沉；没有升级风险时进入周期报告继续判断。
- `/test/simulations` 有草稿时把最近未完成考试作为唯一主行动，其余草稿折叠，已确认考试进入只读历史；创建表单不与历史记录争夺第一屏。
- 模拟详情按“录入成绩 -> 分析失分并确认事实 -> 安排补救”推进。草稿期不显示补救入箱命令；确认后成绩与失分只读，才允许将选中补救送入学习安排收件箱。
- 补救入箱不直接创建正式任务。页面按稳定 `originKey + originVersion` 回读每条补救当前 Inbox 状态；已入箱、已忽略或已转换项保持选中并禁用，刷新后不重复发送。全部处理后主接力进入 `/roadmap/allocation/drafts`，次级入口进入 `/roadmap/stages` 重新评估阶段；阶段路线仍由阶段页独立确认。若从投入草稿详情回看来源考试，模拟详情的投入草稿与阶段出口继续携带该详情上下文。

## 跳转与返回规则

1. 列表到详情：携带安全的 `returnTo` 或由 canonical 父路由推导返回目标，保留筛选、搜索、日期和滚动位置。
2. 启动专注或快速复习：必须携带来源；快速复习完成后回到同一来源，专注完成后主接力回到今日下一行动，同时保留原来源作为次操作。
3. 跨域关联：从任务进入知识对象、从模拟进入补救任务时显示来源摘要，完成后可回原业务对象。
4. 创建成功：优先进入新对象详情；批量创建则返回列表并显示结果摘要。
5. 删除或归档成功：返回最近的有效父列表；禁止返回已经不存在的详情。
6. 未保存表单：编辑器内显式关闭沿用各自的保留或放弃流程；站内离开依靠本机草稿恢复，浏览器刷新或关闭使用原生离开提醒。

来源返回使用统一契约：所有来源先经过注册路由与查询参数白名单归一化，拒绝外部 origin、协议相对地址、登录/初始化页与 hash；逐级返回最多保留三跳，每一跳都重新归一化。返回文案按工作台显示“返回学习安排 / 收件箱 / 资料 / 复习队列 / 晚间复盘 / 阶段概览”等具体来源，不再用无法判断去向的“返回原页面”。每日复盘、周期报告、阶段处理结果和模拟补救进入学习安排收件箱时，也必须保留结果页及其合法筛选参数，避免处理草稿后丢失判断上下文。列表详情仍由会话级返回记录恢复筛选、滚动位置和焦点，不能用通用链接替换该机制。

## 页面状态契约

- 登录后的路由加载态保留 App Shell 和当前工作台语境，只替换内容区；骨架按标题、摘要和列表带稳定占位，不模拟某个特定首页。
- 工作台渲染异常在当前 Shell 内展示，主操作是重试；次操作按当前路由返回知识、复盘、阶段、设置、学习安排、收件箱或今日，不统一跳回首页。
- 动态详情不存在时使用所属工作台的未找到状态，并明确说明没有改动其他记录；全站未知路由才使用根 404。
- 页内空结果继续使用紧凑的无结果状态；有明确下一行动时提供一个出口，没有行动时不添加装饰性按钮。
- 页面异常、业务校验失败和保存成功是三种不同状态：路由异常由 error boundary 处理，业务反馈使用页内 `Alert`，按钮进行中状态保持原尺寸并禁止重复提交。
- 任务、考纲、卡片、错题、资料与晚间复盘的编辑状态统一区分“与服务端一致 / 未提交且已保存在本机 / 正在保存到服务端 / 已保存到服务端 / 需要处理版本冲突”。本机草稿不是服务端成功，不能使用成功色或“已保存”短句混淆。
- 上述编辑器存在本机草稿时，浏览器关闭或刷新使用原生离开提醒；站内离开后重新进入会恢复受 TTL 和用户/工作区范围约束的私密草稿。编辑器内显式关闭或放弃仍使用现有确认与清理流程。
- 核心编辑器共用底部操作区：每次只突出一个服务端提交动作，取消、关闭或放弃位于次级位置；移动端操作按钮纵向全宽排列，主动作保持第一视觉优先级。
- 卡片、错题和资料进入编辑状态后，页头不再同时展示保存与归档。归档、恢复等生命周期动作只在非编辑状态出现；版本冲突存在时普通保存禁用，用户必须先采用服务端版本或保留本地输入并人工合并。
- 操作区左侧只说明本次提交的原子边界或放弃后果；业务失败统一显示页内错误反馈，进行中按钮保持尺寸并禁止重复提交。
- 归档卡片、错题、资料或考纲节点前使用统一确认弹窗，明确对象将变为只读、活动复习排期会暂停，且恢复对象不会自动恢复排期。确认后仍停留在详情页，展示归档状态和直接恢复入口。
- 恢复属于可逆且不覆盖正文的操作，不增加二次确认；任务放弃需要确认并说明会写任务债务事件、之后仍可补做恢复。
- “放弃编辑”仅在确有未提交修改时确认，确认后清除本机草稿并回到服务端基线；没有修改时直接退出编辑。确认弹窗在移动端使用纵向全宽按钮，取消在次级位置，危险确认使用危险色。
7. 非法或过期深链：回到所属工作台的默认入口，并说明对象不可用；不一律静默回 `/today`。

## 响应式与密度

- `>= 1440px`：允许三栏 split-view 和宽屏 dashboard；信息密度最高。
- `1024-1439px`：侧栏可折叠，split-view 使用列表 + 详情两栏。
- `768-1023px`：侧栏转为抽屉或底部导航，dashboard 辅列移到主列下方。
- `< 768px`：所有工作流单列，详情独立成页，表格改为带标签的行，不做横向挤压。
- 长文本、复盘正文和设置表单始终限制可读行宽；画布、时间轴、趋势图和列表工作台使用完整内容宽度。

## 重构验收

- 五个一级入口及默认目标与本文一致。
- 知识默认进入概览，复盘默认进入今日复盘。
