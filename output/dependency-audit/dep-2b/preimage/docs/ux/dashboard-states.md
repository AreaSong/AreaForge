# 首页状态

## 正常推进

- 展示完整作战台。
- 今日推荐任务在第一屏。
- 计时按钮明显。
- 鞭策文案保持冷静压强。

## 连续高完成

- 突出连续打卡、累计有效时长和阶段突破。
- 不降低目标，只提高下一步压强。

## 断签警报

- 提高欠账、风险等级、恢复动作的视觉优先级。
- 减少无关信息。
- 明确今天最小任务。

## 恢复模式

- 今日只展示 1 个最小可执行任务。
- 计时目标 30 到 90 分钟。
- 不展示大量欠账压迫用户。

## 冲刺模式

- 前置倒计时、真题、模拟分、错题复盘。
- 弱化长期愿景，强化当天结果。

## 行动中心状态

当前产品已落地行动中心契约：

- 首次使用：无当前考试工作区时只展示设置考试目标，不堆空白统计或说明墙。
- 空队列：三队列皆空时主动作为「创建今天最小任务」。
- 五个全局状态灯（活动、复习、欠账、阶段、今日闭环）；移动端合并为单一最高优先级状态按钮。
- 恢复三阶与 expired；页面主内容最多一条状态栏与一个主动作，说明进入 Popover/Drawer/Modal。
- `/focus` 是手动“开始学习”入口，今日行动中心为 `/today`，任务详情 canonical 为 `/roadmap/allocation/tasks/[taskId]`。登录默认落点由统一入口判断：无工作区先设置，有活动先恢复，无活动进入今日判断。
- 今日时长、科目分布和近期记录只展示可追踪事实；无数据时不生成固定分钟、积分、比例或趋势。
- 目标考试和模拟倒计时读取当前工作区真实日期；缺少日期时保持未设置，不触发冲刺或模拟窗口。
- 首屏用三阶段进度轨区分行动、可选证据和每日复盘；断点续学只在没有活动和恢复状态时出现。
- 推荐反馈使用“适合当前节奏”和“暂时换一项”；反馈保存失败保留当前推荐，推荐已变化时载入服务端最新行动。
- 每日复盘入口按事实显示“完成今日复盘”“结束学习并复盘”或“今日已闭环”，避免已完成状态仍展示重复命令。

权威 UX 矩阵见 `workflow/versions/v1.1-learning-action-center.md`。
