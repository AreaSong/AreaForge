# 任务计划

## 目标

任务计划用于管理每天应该完成什么，并和计时、大纲、笔记、错题、复盘关联。

## 字段

- 科目。
- 任务标题。
- 任务类型。
- 预计时长。
- 实际时长。
- 优先级。
- 完成状态。
- 所属大纲节点。
- 相关考纲节点。
- 所属阶段（可多个）。
- 关联知识点（可多个）。
- 完成后的复盘记录。

## 科目来源

- 普通 seed 不创建业务科目；用户在首次设置中创建自己的科目和分组。
- “考研公共课”和“计算机统考 408”只是默认未选中的版本化模板。用户显式选择后复制为普通科目数据，随后可编辑、排序、归档或合并。
- 任务只引用当前 Workspace 中的普通 `Subject` 记录，不根据科目名称或 408 code 走隐藏分支。

## 任务类型

- 用户可创建：学习 `study`、复习 `review`、刷题 `practice`、错题 `mistake`、模拟 `simulation_exam`。
- `focus` 是历史/系统兼容类型，不出现在用户新建选项中，但旧任务仍可查看和编辑。
- 类型值、中文标签、创建校验和 UI 选项读取 `packages/core` 共享目录；状态机和系统策略枚举不提供用户 CRUD。

## 状态

- 待开始。
- 进行中。
- 已完成。
- 已延期。
- 已放弃。

## 规则

- 未完成任务进入任务债务系统。
- 完成任务后可以触发鞭策文案。
- 任务可以关联到学习计时。
- 任务可以关联到主考纲节点、多个相关考纲节点、多个阶段、多个知识点和笔记。
- 知识点是独立对象，不会因为任务创建而复制；同一知识点可跨任务、阶段、考纲和多次检验复用。
- 创建、更新和拆小任务均保持关系完整性；拆小任务继承父任务的里程碑、考纲、阶段和知识点关系。

## 当前行为

- 今日、滚动计划和任务详情读取同一任务类型目录；新建拒绝未知类型，编辑兼容历史 `focus`，任务卡片展示统一中文标签、状态和预计时长。
- 拆小任务通过 `StudyTask.parentTaskId` 建立父子关系，债务动作同步写 `TaskDebtEvent` 事件账本。
- 重排建议支持确认、驳回和用户所选项应用记录，从不自动应用。
- 批量任务调整或自动阶段联动不在当前范围，需单独确认。
