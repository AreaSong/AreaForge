# 工作区持久搜索

## 数据与权限

搜索只处理科目、任务、知识点、笔记、错题和资料的名称或标题。科目遵循工作区可见性，其余只返回本人资源或有效 NOTE/MISTAKE grant 所允许的资源；Workspace Owner、Coach 和平台 Operator 不因此获得他人私有标题。
不收录正文、附件名或内容、动机、情绪、AI 数据与搜索历史，也不调用外部搜索服务。

`WorkspaceSearchPartition` 按用户与工作区唯一，保存请求代次和已发布代次；`WorkspaceSearchDocument` 绑定分区、工作区、代次、类型和六类源对象之一。复合外键保证工作区一致，CHECK 保证恰好一个源外键及 kind/sourceId 一致。
索引是可重建派生数据，不是学习事实或授权源。入队、准备、发布和读取都重验当前账户、会话或执行身份、Membership、角色/grant、源修订、归档和冻结状态；改名后改回、撤销后重新授权也不恢复旧请求的效力。

## 请求、执行与读取

- `GET /api/search`：只读查询，保持不区分大小写的包含匹配、六类结果、结果上限和 canonical href。响应的 `indexed/indexState/indexedAt` 区分有效索引、未建、失效与关闭；不能证明有效时不返回旧索引标题、计数或时间。
- `GET /api/search/index`：读取本人在指定工作区的索引和最近任务，不自动创建任务。
- `POST /api/search/index`：显式请求，绑定当前用户、工作区、`expectedGeneration` 和幂等键；不明确的回执使用同一请求重试。
- `PATCH /api/search/index/jobs/:jobId`：按任务 revision 暂停、恢复、取消或人工重放。只有请求者本人可以控制；恢复或重放不能重绑到变化后的权限或源集合。

`SEARCH_INDEX_ENABLED`、`SEARCH_INDEX_QUEUE_ENABLED` 均默认关闭。索引读取需要 AUTH/RBAC 与索引开关；入队、准备和提交还要求队列开关与 `DATA_JOB_WORKER_ENABLED`。Web 只登记与显示，独立固定处理器消费 `SEARCH_INDEX_REBUILD`，不启动进程、不增加定时任务。
整代文档、发布指针、审计和任务成功同事务提交；旧代次、旧租约、取消、暂停、超时或源变化均不能留下半代成功。准备后、文档写入后但提交前的中断按持久租约恢复。
成功回执只证明该次发布事务完成；源变更可以序列化到发布之后，授权也可能随后到期。查询仍重验当前来源与授权，不能把任务成功当作索引持续有效的证明。

显式新建索引任务还可受[后台任务准入配额](data-job-quotas.md)约束；超限不增加任务或索引代次，搜索直查及已有任务控制不受此准入限制。配额不是索引文档/标题容量保护。

## 有界回退

每分区最多 10,000 文档，每标题最多 8 KiB，整次标题最多 16 MiB；检查字节数后才复制标题。提交预算为 15 秒，权限/删除/分区锁冲突有界失败，不阻断学习源写入。
这些是索引资源护栏，不是用户业务配额。索引关闭、失效、容量超限或分区占锁时，搜索回退到同样经过当前权限和冻结校验的源查询。
授权集合只在数据库内计算，排序/分页后只锁最终候选所需的 grant，并在返回前重验到期；全分区 grant 或全库 fence 的索引快照上限不会关闭安全直查。索引事务发生 SQL 锁错误后，回退使用新事务，不能在已终止事务中继续。
取消已有任务只校验当前身份、工作区、任务所有权与冻结，不要求超限的索引集合重新成为可重建状态。

## 删除与导出

两张索引表都从用户导出排除；获分享的标题副本不属于查看者自有数据。
查看者删除只清自己的分区与副本，不反向扩展到他人源；源所有者删除只把类型、源外键和分区工作区绑定一致的精确副本纳入闭包。
源已迁往另一工作区时，精确旧搜索副本仍可清除；其他模型、原工作区 grant 或外人引用继续按既有删除规则阻断，不借搜索例外扩大删除权。
冻结旧文档保留原 rowHash/fence；重建排除冻结源并仅回收本分区未冻结旧文档。恢复后重新验证来源，不把旧发布指针当作当前有效证明。

## 体验、验证与回退

“设置 → 数据与安全 → 我的搜索索引”提供工作区选择、请求、任务进度、控制与折叠历史；顶部保留搜索入口。用户/工作区或输入变化会作废迟到响应，状态刷新失败隐藏未验证的计数并保留恢复操作。
验证运行 `worker:search:typecheck`、`worker:search:isolation:selftest`、专用合成库 `worker:search:runtime:selftest` 和复用测试池的 `worker:search:browser:selftest`；完整 profile 见[验证矩阵](../development/validation-matrix.md)，实际交付见[平台加固任务](../../tasks/backlog/0045-platform-hardening.md)。
回退时关闭生产者/消费者，搜索使用安全直查；保留兼容表、任务、审计和冻结证据，不 DROP 表、不恢复已撤销访问。共享库、生产、Release、备份恢复和 residual 关闭仍需各自确认。
